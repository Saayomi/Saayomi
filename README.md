**Frontend Development · Accessible Interfaces · Web Experiences**

I'm a software developer with a focus on frontend development and the details that make web applications clear and comfortable to use. My interests connect interface design, application behavior, and accessibility.

## What Interests Me

- **Responsive interfaces** that adapt thoughtfully to different screens and content.
- **Accessible interactions** that support keyboards, readable content, and clear navigation.
- **Reusable components** with consistent behavior and understandable responsibilities.
- **Forms and application flows** that explain requirements, progress, and recovery steps.
- **API-driven experiences** that handle loading, empty results, errors, and successful actions clearly.

## Frontend Focus

| Area | Questions I Want to Explore |
| --- | --- |
| Interface structure | How can layout and hierarchy help people understand what to do next? |
| Responsive design | How should content adapt without losing meaning on smaller screens? |
| Accessibility | Can someone navigate and complete a task using a keyboard or assistive technology? |
| State and data | How can the interface communicate what is happening during a request? |
| Components | Which patterns should be shared, and which need their own behavior? |
| Testing | How can tests verify the tasks a user needs to complete? |

## Development Priorities

- Start with the task someone needs to accomplish.
- Use clear content, semantic structure, and predictable interactions.
- Consider loading, empty, error, and success states together.
- Check keyboard behavior and layouts across screen sizes.
- Keep components readable and document decisions that affect other developers.
